# 首都戦記 (Shuto-battle)

東京都デジタルツイン実現プロジェクトの CC BY 4.0 データを基に、1/1スケールで簡略化した3Dマップを使ったブラウザ向けプロトタイプです。

## 内容

- **視点**: 1人称視点（武器/腕が見えるFPSスタイル）
- **ステージ**: `新宿駅周辺`・`渋谷駅周辺` の独立ステージ（駅周辺エリア、相互接続なし）
- **スケール**: 1/1スケール（1単位=1m）を基準にステージを構成
- **操作**: 画面左下の指スティック（タッチ/マウス）で移動、WASD/矢印キーも可
- **当たり判定**: 建物・樹木・ステージ境界に当たり判定あり
- **表示**: 右下に現在地点の半透明2Dミニマップ
- **オクルージョン**: 視界を遮る近距離の建物は半透明化

## 起動方法

```bash
python3 -m http.server 8000 --bind 0.0.0.0
# ブラウザで http://localhost:8000 を開く
```
