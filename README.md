# 首都戦記 (Shuto-battle)

東京都デジタルツイン実現プロジェクトの CC BY 4.0 データを基に簡略化した地図データを使った、ブラウザ向けの簡易ゲームプロトタイプです。

## 内容

- **エリア**: 新宿・渋谷の 2 エリア
- **操作キャラ**: フィールドエージェント（主人公）をキーボードで移動可能
- **表示**: エリア境界、ランドマーク、現在地 HUD

## 操作方法

- `W` / `A` / `S` / `D` または矢印キー: 移動
- キャラがいるエリアが画面上部の HUD と右側パネルに表示されます

## 起動方法

ビルド不要の静的ファイル構成です。任意の静的サーバーでリポジトリルートを配信してください。

```bash
# 例: Python
python3 -m http.server 8000

# 例: Node.js (npx)
npx serve .
```

ブラウザで `http://localhost:8000` を開きます。

## ファイル構成

- `index.html` - メイン画面
- `style.css` - UI スタイル
- `game.js` - ゲームロジック（移動・描画・エリア判定）
- `data/areas.js` - 新宿・渋谷の簡略化エリアデータ
