# 首都戦記 (Shuto-battle)

東京都デジタルツイン実現プロジェクトの CC BY 4.0 データを基に簡略化した3Dマップデータを使った、ブラウザ向けの3Dゲームプロトタイプです。

## 内容

- **視点**: 三人称視点（キャラの後方から追従）
- **エリア**: 新宿駅周辺・渋谷駅周辺の 2 エリア（区全体ではなく駅周辺のみ）
- **操作キャラ**: フィールドエージェント（主人公）をキーボードで移動可能
- **表示**: 3D建物、道路、ランドマーク、現在地HUD

## 操作方法

- `W` / `A` / `S` / `D` または矢印キー: 移動
- `Shift`: ダッシュ
- キャラがいるエリアが画面上部の HUD と右側パネルに表示されます

## 起動方法

ビルド不要の静的ファイル構成です。任意の静的サーバーでリポジトリルートを配信してください。

```bash
# 例: Python
python3 -m http.server 8000 --bind 0.0.0.0

# 例: Node.js (npx)
npx serve .
```

ブラウザで `http://localhost:8000` を開きます。

## ファイル構成

- `index.html` - メイン画面（importmapでThree.jsを読み込み）
- `style.css` - UIスタイル
- `game.js` - Three.jsによる3D描画・三人称カメラ・移動・エリア判定
- `data/areas.js` - 新宿駅周辺・渋谷駅周辺の簡略化3Dエリアデータ
- `vendor/three.module.js` - Three.js（ローカル配置）
