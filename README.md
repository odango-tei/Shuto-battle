# 首都戦記 (Shuto-battle)

東京都デジタルツイン実現プロジェクトの CC BY 4.0 データを基に簡略化した3Dマップデータを使った、ブラウザ向けの3Dゲームプロトタイプです。

## 内容

- **視点**: 三人称視点（主人公の後方から追従）
- **ステージ**: `新宿駅周辺`・`渋谷駅周辺` の2ステージ（駅周辺のみ、区全体ではない）
- **ステージ構成**: 新宿と渋谷は独立したステージで、互いに接続されていません（ステージ選択で切り替え）
- **操作キャラ**: フィールドエージェント（主人公）が地面上に立って移動
- **当たり判定**: 建物・樹木・ステージ境界に当たり判定あり

## 操作方法

- **画面左下のジョイスティック**: 移動（タッチ/マウス対応）
- `W` / `A` / `S` / `D` または矢印キー: 移動（PC向けフォールバック）
- 画面上部のステージボタン、または右パネルのステージ一覧からステージ切り替え

## 起動方法

ビルド不要の静的ファイル構成です。任意の静的サーバーでリポジトリルートを配信してください。

```bash
python3 -m http.server 8000 --bind 0.0.0.0
# ブラウザで http://localhost:8000 を開く
```

## ファイル構成

- `index.html` - メイン画面（HUD・ステージ選択・ジョイスティックUI）
- `style.css` - UIスタイル
- `game.js` - Three.jsによる3D描画・三人称カメラ・移動・当たり判定・ステージ切替
- `data/areas.js` - 新宿駅周辺・渋谷駅周辺の簡略化3Dステージデータ
- `vendor/three.module.js` - Three.js（ローカル配置）
